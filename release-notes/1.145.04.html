What's New in 1.145.04

Point release on 1.145.03. Adds a post-encode Output Audit Report so you can verify every file before deleting the original, fixes missing colour tags on BRAW and RED outputs, and closes a set of watch-folder problems on network shares and external drives.

  • New: Output Audit Report — When a queue finishes, PME reads every output back and reconciles it against what the encode settings intended — frame count, duration, resolution, codec, colour, and audio — then exports a clean PDF (optionally CSV / JSON) you can keep as proof before deleting the source. Each file is marked Verified, Needs review, or Failed, and only a fully-passing file gets a "Safe to archive original" line. Comparisons are three-way — Source vs. Expected (from your settings) vs. Actual (read from the file) — so intentional changes like a downscale or codec conversion read as "As configured," not as errors. Frame count is exact, counted from the file itself.
  • New: Three Ways to Run the Audit — A per-clip "Generate audit report" toggle in Encoding settings (saved with presets, works in batch multi-select); an app-wide "Audit every output" switch in Settings → Output Audit; and right-click Audit Output / Export Audit Report… on any completed job (or multi-select for a combined report). Pick which lines appear in each format with the Report Fields matrix, and choose where reports are saved. RAW sources and off-speed / slow-motion clips are handled correctly — a 3-second audio track against 24 seconds of slow-mo video reads as a match, while a genuinely truncated track still fails.
  • Fixed: BRAW & RED (R3D) Outputs Now Colour-Tagged — HEVC and ProRes outputs from the BRAW and R3D pipelines were being written with no ColorPrimaries / TransferFunction / YCbCrMatrix tags, forcing players to guess the colour space. Video-look develops (Rec.709 / BMD Video / BMD Extended Video for BRAW; Rec.709 / sRGB with an SDR display gamma for R3D) are now tagged Rec.709, matching the H.264/MXF path. Log, HDR, and wide-gamut develops (BMD Film, Log3G10, PQ, HLG, Rec.2020, DCI-P3, etc.) are correctly left untagged so they can't be mislabelled. Surfaced by the new audit.
  • Fixed: Watch Folders — Network Share Reliability — A stale SMB mount can no longer beachball the app (all watch-folder disk access now runs off the main thread), background reconnects can't hang forever behind an invisible auth prompt (60-second watchdog, "no UI" mode, critical for headless pme watch), and mount errors now say "authentication failed — check username and password" or "server unreachable" instead of "Mount failed (status 17)." Alternate mount points (/Volumes/Share-1 when /Volumes/Share was taken) are followed transparently, NFS automounts and shares outside /Volumes are diagnosed correctly, and duplicate mounts from two watch folders racing on the same share are prevented.
  • Fixed: Watch Folders — No Lost Configs, No Lost Files — Launching PME while a watch folder's drive or share was unavailable used to silently delete that configuration; configurations are now always kept and the folder just shows its error state until the volume returns. A file that fails probing (or is blocked by licensing) is now moved back into the watch folder with a logged reason instead of vanishing into PickedUp. A NAS whose clock is ahead of the Mac's no longer prevents files from ever being picked up (stability is now measured on the Mac's own clock). And two files with the same stem from different subfolders (A001/clip.mxf, A002/clip.mxf) no longer overwrite each other in a single batch.
  • Fixed: Watch Folders — Snappier Controls — Stop takes effect in about a second (previously up to the full polling interval, and a quick stop→start could leave a duplicate loop running). Scan Now also wakes a folder sleeping in error/reconnect backoff, and a successful manual Mount kicks off a rescan immediately. Pointing one watch folder's output inside another watch folder's tree is now rejected up front instead of causing files to be re-picked-up and transcoded forever, and / or : in a filename suffix can no longer silently redirect outputs elsewhere.
  • Updated: Acknowledgements — Settings → Acknowledgements now covers every third-party library and SDK shipped with the current build (Sparkle, FFmpeg, libMXF, swift-argument-parser, RED R3D, Blackmagic RAW, Canon Cinema RAW Development SDK, and — in ARRI variants — the ARRI Image SDK and its bundled OSS components). Full license texts (including the GNU LGPL v2.1 for FFmpeg) are now bundled and viewable inline.
